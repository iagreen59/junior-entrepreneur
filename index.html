How to play

  1. Start with $50. Buy your first stand for $20 before you can Sell Day.
  2. When cash is over $100, you may Add stand ($20) up to 4 stands. Use the dropdown to switch which stand you are managing. All stands share one supply bag.
  3. With 2+ stands, staff every stand: you may run one yourself; hire employees for the others (or run all with employees). Wage is $5/day per employee, paid on Sell Day. Understaffed stands block Sell Day.
  4. You may Sell a stand for $10 (keep at least one). Rare morning events (good or bad) show a banner — supply prices, an employee quitting, or a foot-traffic surge. Impacts are temporary and recoverable.
  5. Check today’s Weather, toggle today’s Menu, then pick which item to edit (Juice, Hot cocoa, Burger, or Soup).
  6. Set the Recipe, Buy ingredients, set a Price for each offered item, then Sell Day (customers choose among everything on today’s menu).
  7. Use New Game anytime to reset your save.

    Before you sell

    1. Own a stand (buy one if you haven’t yet; add more when cash > $100).
    2. With 2+ stands, staff every location (you +/or employees).
    3. Check today’s Weather (hot / mild / cold).
    4. Set Today’s menu toggles (at least one item on).
    5. For each offered item: check Recipe, Buy stock, set Price.
    6. Press Sell Day — customers choose among offered items (~10s); wages are paid then.
